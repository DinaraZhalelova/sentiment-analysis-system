# Sentiment Analysis System

Учебное веб-приложение для курсового проекта «Разработка системы анализа тональности текста».

## Функции
- анализ русскоязычного текста;
- три категории: положительная, нейтральная, отрицательная;
- оценка уверенности модели;
- примеры текстов для быстрой проверки;
- обработка пустого ввода и ограничения длины (4000 символов);
- SQLite-история анализов, просмотр и очистка;
- отдельная история для каждого браузерного сеанса;
- резервный словарный анализ, если ML-модель не загружается.

## Запуск на Windows
1. Установите Python 3.10–3.12.
2. Распакуйте архив.
3. Откройте CMD в папке проекта и выполните:

```bat
py -m venv .venv
.venv\\Scripts\\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

4. Откройте http://127.0.0.1:5000

При первом анализе приложение попытается скачать модель `cointegrated/rubert-tiny-sentiment-balanced` с Hugging Face. Нужен интернет, а загрузка может занять время. Если модель недоступна, приложение продолжит работу в резервном словарном режиме. Этот режим упрощённый и не равен полноценной ML-модели.

## Структура
- `app.py` — Flask-сервер, анализ и SQLite;
- `templates/index.html` — HTML-интерфейс;
- `static/style.css` — стили;
- `static/app.js` — взаимодействие с API;
- `requirements.txt` — зависимости;
- `history.db` — создаётся автоматически при первом запуске.

Оценка уверенности не является гарантией правильности. Модель может ошибаться на сарказме, иронии, сленге и текстах без контекста.
